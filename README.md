# OLA Ride Booking Analysis

## Project Overview
This project analyzes OLA ride booking data to understand booking performance, revenue generation, cancellation patterns, vehicle-type performance, and customer and driver ratings.

The project combines data cleaning, SQL-based analysis, and an interactive Power BI dashboard to turn raw booking data into meaningful business insights.

## Objectives
- Analyze total, successful, and cancelled bookings.
- Examine booking trends over time.
- Compare ride distance and booking value across vehicle types.
- Identify customer and driver cancellation patterns.
- Analyze revenue by payment method.
- Evaluate customer and driver ratings across vehicle types.

## Tools & Technologies
- **Python (Pandas):** Data cleaning and preprocessing
- **MySQL:** Data analysis using SQL queries
- **Microsoft Power BI:** Interactive dashboards, KPIs, and visualizations

## Dataset
The dataset contains 103,024 ride booking records and includes information such as booking date, booking status, vehicle type, customer ID, pickup and drop locations, ride distance, booking value, payment method, cancellation reasons, and customer and driver ratings.

## Project Workflow
1. Explored the raw ride booking dataset.
2. Cleaned and prepared the data using Python.
3. Analyzed business questions using MySQL.
4. Created an interactive Power BI dashboard.
5. Developed insights into booking performance, revenue, cancellations, and ratings.

## SQL Analysis
The SQL analysis addresses questions such as:
- Retrieving successful bookings.
- Calculating average ride distance by vehicle type.
- Identifying the most common vehicle types.
- Finding the top customers by number of rides.
- Analyzing customer and driver cancellations.
- Calculating maximum and minimum driver ratings.
- Evaluating booking value for completed rides.
- Identifying incomplete rides and their reasons.
